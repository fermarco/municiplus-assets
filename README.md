# municiplus-assets

Hosting pubblico per le immagini generate automaticamente per i contenuti MUNICIPLUS (copertine articolo, visual dei post social).

Repository pubblico per una sola ragione tecnica: Buffer e Notion leggono l'URL di un'immagine senza autenticazione. Un repository privato o un URL Notion temporaneo non funzionano in questo flusso — vedi `fermarco/agentmuniciplus`, `scripts/visuals/README.md`.

Non contiene nient'altro che grafiche generate dal motore in `fermarco/agentmuniciplus/scripts/visuals/`. Non è un sito, non ha logica propria.
